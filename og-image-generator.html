📸 So erstellen Sie das OG-Image:

  1. Browser-Zoom auf 100% setzen
  2. Screenshot-Tool öffnen:
    • Windows: Snipping Tool oder Win + Shift + S
    • Mac: Cmd + Shift + 4
    • Oder: Browser DevTools → Screenshot (exakte Größe)
  3. Nur den grauen Container (1200×630px) erfassen
  4. Als JPG speichern: og-image.jpg
  5. In Ordner verschieben: assets/og-image.jpg
💡 Profi-Tipp: Nutzen Sie ein Tool wie Canva oder Figma für pixelgenaue Ergebnisse (1200×630px Template).
🎨 Alternative: Ich kann Ihnen auch einen Canva-Link oder Figma-Vorlage mit Ihren CI-Farben erstellen!
